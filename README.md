# Weather App

## 🌦 Overview

This is a simple and responsive Weather App built using React and Vite. It fetches real-time weather data using an external API and displays essential weather information based on the user's search.

## 🚀 Features

- Search weather by city name
- Real-time location feature to access your current location and display weather data
- Displays temperature, humidity, wind speed, and weather conditions
- Shows weather icons based on current conditions
- Responsive design for mobile and desktop

## 🛠️ Technologies Used

- React.js
- Vite
- OpenWeatherMap API
- JavaScript (ES6+)
- CSS

## 📦 Installation & Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/kartiksoni-24/Weather_App.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Weather_App
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

## 🔧 Usage

1. Open the app in your browser.
2. Enter a city name in the search bar and press enter.
3. Click on "Search by Location" to allow the app to fetch weather data based on your real-time location.
4. View real-time weather details of the searched city or your current location.

## 🌍 API Integration

This app uses the OpenWeatherMap API to fetch weather data. To run the app, you need an API key:

1. Sign up at [OpenWeatherMap](https://openweathermap.org/) and get your API key.
2. Create a `.env` file in the project root and add your key.
3. Restart the development server.
